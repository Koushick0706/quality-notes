## Preview

Open `index.html` in a browser. For a local web server, run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Publish and share

The site is ready for GitHub Pages as a separate repository from the Playwright project. Create a public repository named `quality-notes`, add these site files to its `main` branch, then enable **Settings → Pages → Deploy from a branch → main → /(root)**. GitHub's Pages URL will be `https://koushick0706.github.io/quality-notes/` after the first deployment completes.

Once the public site URL is available, use **Share this site** to open LinkedIn's share composer. LinkedIn needs the public URL to create a share preview; local file and localhost links will not be visible to your network. Each Medium card opens its original article, where you can use Medium's sharing controls.

The share buttons open LinkedIn's share composer. Review the preview and write or edit your post there before publishing.
